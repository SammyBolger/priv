# other

Scratch folder for reference docs that live alongside the code but
aren't part of the published site.

Docusaurus only publishes what's under `docs/` and `src/pages/`, so
anything dropped here stays private to the repo. Handy for one-pagers,
draft designs, integration briefs, and diagrams that Michael or the EA
team want visible in-repo without going through the KB publish flow.

Current contents:

- `AI4EA Diagram.md` — target GCP deployment topology (IAP, Cloud Run,
  Cloud Storage/CDN, LiteLLM gateway, Vertex AI). Reference for the
  GCP migration.
- `Application-Support.md`
- `ariba-workday-integration.md`
- `ea-design-structure.md`
- `ECC_to_S4_AI4EA_Recommendations.md`
- `RA-SA-Artifact-Standard-Guardrail-Alignment-Review.md`
- `RA-Template-Confluence.md`
- `workday-ariba-user-provisioning-one-pager.md`

Drop new reference material here freely. If something graduates into
canonical KB content, move it into the right subfolder under `docs/`
and add it to `sidebars.ts`.
